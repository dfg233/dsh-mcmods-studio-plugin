# 图形化数据编辑规格

> 状态：目标设计，未实现
> 归属：[../PLAN.md](../PLAN.md) M1
> 最后更新：2026-10-29

## 1. 目的

让用户不读 Java、不手写 JSON，也能修改模组的“数据”：

- 物品属性；
- 配方；
- 标签；
- 语言；
- 模型选择；
- 后续：方块属性、战利品表、创造标签成员。

不把 Java 行为做成图形节点。

## 2. 三层数据

| 层 | 例子 | 图形化 | 生效方式 |
| --- | --- | --- | --- |
| 资源 JSON | 配方、标签、语言、模型、blockstate | 是 | 直接写工程文件 |
| 设计数据 | 物品属性、方块属性、创造标签成员 | 是 | 代码生成或任务 |
| 代码逻辑 | 事件、网络、GUI、状态机 | 否 | 模板 + 任务 |

每次编辑必须告诉用户：这次改的是哪一层、会不会立刻在游戏里生效。

## 3. MVP 范围（v0.2）

### 物品属性

- 最大堆叠；
- 最大耐久；
- 攻击伤害；
- 食物恢复值；
- 稀有度；
- 附魔光效。

已有 19 字段编辑器保留；MVP 只强化高频字段的内联编辑与校验。

### 配方

- 有序配方（3×3）；
- 无序配方；
- 熔炉配方；
- 产出数量；
- 材料合法性校验。

### 标签

- 物品标签；
- 方块标签；
- 常用标签自动补全；
- 引用不存在的 id 时警告。

### 语言

- `zh_cn` / `en_us` 两列；
- 缺失键高亮；
- 新增/修改/删除；
- 不覆盖未知键。

### 模型

- `item/generated`；
- `item/handheld`；
- 自定义 JSON；
- 与贴图引用一致性检查。

## 4. 交互

```text
物品列表 → 点击物品 → 右侧面板
  [属性] [配方] [标签] [语言] [模型]
  → 修改 → 即时校验
  → “应用到工程”
  → 预览：设计数据 / 资源文件 / 代码或任务
  → 确认 → 备份 → 写入或生成 → 刷新
```

- 列表内联编辑常用字段，减少弹窗；
- 非法值即时提示；
- AI 提议的修改以 diff 展示，不直接落盘；
- 每次应用前自动备份，支持撤销；
- 预览必须区分三类改动，避免“以为改了游戏数据，其实只改了设计稿”。

## 5. 应用管线

```text
修改
  → 校验（id、数值范围、资源引用、模板）
  → 生成变更集
  → 分类：
      1) .mcstudio 设计数据
      2) assets/data 资源 JSON
      3) Java 代码或任务
  → 预览 diff
  → 备份
  → 应用
  → 重建 summary / structure
  → 返回结果与回滚点
```

- 第 1 类：只影响插件设计数据，不直接改变游戏；提示用户“需要生成代码/任务”；
- 第 2 类：写入资源文件，游戏可直接读取；
- 第 3 类：进入代码生成预览或任务包，不静默改 Java。

## 6. 与 AI 的协作

- AI 通过 `content.patch` 提议字段变更，不直接写文件；
- 插件校验后返回 diff，由用户确认；
- AI 可以解释“为什么这个值不合理”，但不能绕过校验；
- 用户手动修改优先，AI 不覆盖未确认的本地草稿。

## 7. 数据与文件

```text
<项目>/.mcstudio/items/<id>.json         # 设计数据
<项目>/src/main/resources/data/<modid>/recipes/*.json
<项目>/src/main/resources/data/<modid>/tags/**/*.json
<项目>/src/main/resources/assets/<modid>/lang/*.json
<项目>/src/main/resources/assets/<modid>/models/item/*.json
```

设计数据与资源文件分开；不要把配方/语言写进 `.mcstudio`。

## 8. 安全与边界

- 不覆盖未知 JSON 键；
- 不删除用户手写的配方/标签；
- 写入前备份；
- 非法 JSON 不落盘；
- 不自动改 Java；
- 不把 `build/`、`.gradle/`、`generated/` 作为编辑目标。

## 9. 验收

- 用户能在 3 分钟内完成“物品 + 配方 + 中英文名 + 模型”；
- 应用前能看到将改哪些文件；
- 非法值被拦截；
- 失败可回滚；
- 设计数据编辑明确提示“需要生成代码才生效”。

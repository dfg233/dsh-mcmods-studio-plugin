# mod 资料页设计（P0 框架）

> 日期：2026-11-15
> 状态：**设计稿，未实现**
> 关联：[V0.5.0-PLAN.md](../major/V0.5.0-PLAN.md)、[CONTENT-EDIT.md](CONTENT-EDIT.md)、[INDEX.md](../INDEX.md)
> 目标：把现有「物品」页升级为「**mod 资料**」页，按 MC百科 的资料分类重新组织，先做框架（分类导航 + 物品迁移 + 其余分类占位），后续按分类接入数据。

## 1. 范围（P0）

- 顶部页签「物品」→「mod 资料」；
- 新增分类导航（MC百科 10 类 + 「添加新资料」入口）；
- 「物品/方块」分类迁移现有物品列表/画布/编辑器；
- 其余分类显示空态占位（0 条，提示由 agent 创建）；
- 「原版资料 / 原版协议」作为来源标签（P0 只做筛选框架，不接数据）；
- **不改**：物品编辑器的字段与保存逻辑、素材与语言页面、其他页签。

## 2. 现状

- 顶部页签：`项目 / 构想 / 计划 / 物品 / 语言 / 贴图与模型 / 构建教程`；
- 「物品」页（`ItemsTab`）：物品列表 + 画布视图、搜索、缩略图、打开 `ItemEditor`（属性/配方/标签/模型等页签）；
- 数据：`.mcstudio/items.json`（物品）、素材（贴图/模型）、语言键；
- 资料分类目前**没有**：物品与方块混在 items 列表，没有生物/群系等分类。

## 3. 分类体系

参考 MC百科资料类型（官方教程列 10 类；截图另含「游戏设定」）：

| # | 分类 | 说明（MC百科） | 数据来源（插件） |
| --- | --- | --- | --- |
| 1 | 物品/方块 | 物品（Item）与方块（Block） | `items.json`（现有） |
| 2 | 生物/实体 | 实体（Entity / Mob） | `entities.json`（后续） |
| 3 | 多方块结构 | 玩家搭建的、形成整体的结构 | `multiblocks.json`（后续） |
| 4 | 游戏设定 | 名词术语、命令、世界观与背景故事 | `settings.json`（后续） |
| 5 | 群系/群落 | 生物群系（Biome） | `biomes.json`（后续） |
| 6 | 附魔/魔咒 | 附魔（Enchantment） | `enchantments.json`（后续） |
| 7 | 自然生成 | 结构（Structure）、地物（Feature）、拼图（Jigsaw） | `worldgen/`（后续） |
| 8 | 世界/维度 | 维度（Dimension） | `dimensions.json`（后续） |
| 9 | BUFF/DEBUFF | 状态效果（Effect） | `effects.json`（后续） |
| 10 | 绑定热键 | 设置中新增的绑定按键 | `keybinds.json`（后续） |
| — | 添加新资料 | 新建资料入口 | 由 agent 创建 |
| — | 原版资料 / 原版协议 | 资料来源标签（截图顶部） | 知识库元数据 |

> 「原版资料 / 原版协议」在截图中是列表顶部的两个标签；P0 先作为来源筛选占位，不区分数据。

## 4. 页面信息架构

```text
[mod 资料]                                   [刷新] [素材]
────────────────────────────────────────────────────────
[原版资料] [原版协议]        ← 来源标签（P0 占位）
┌────────────┬───────────────────────────────────────────┐
│ 分类导航    │ 分类标题（计数） + 简介                    │
│ 物品/方块 N │ 搜索 / 列表 / 画布                        │
│ 生物/实体 N │ ┌───────────────────────────────────────┐ │
│ 多方块    N │ │ 资料卡片 / 空态                        │ │
│ 游戏设定  N │ └───────────────────────────────────────┘ │
│ 群系/群落 N │                                           │
│ 附魔/魔咒 N │                                           │
│ 自然生成  N │                                           │
│ 世界/维度 N │                                           │
│ BUFF/DEBUFF│                                          │
│ 绑定热键  N │                                           │
│ + 添加新资料│                                          │
└────────────┴───────────────────────────────────────────┘
```

- 左侧分类导航：固定 10 类 + 底部「添加新资料」；每项显示分类名与计数（P0 只有「物品/方块」有真实计数，其余 0）；
- 右侧内容区随分类切换；物品/方块分类保留现有列表/画布/搜索/编辑器；
- 顶部来源标签：P0 只渲染「原版资料 / 原版协议」，点击切换高亮，不改变数据（后续接来源字段）。

## 5. 物品/方块分类（迁移）

- 复用现有 `ItemsTab` 的列表/画布、搜索、缩略图、`ItemEditor`；
- 迁移方式：`ItemsTab` 拆为 `ModDataTab`（框架）+ `ItemsSection`（原物品内容）；
- 交互不变：新建/编辑物品仍走现有 `ItemEditor`（agent 也可用工具创建）；
- 分类信息：物品/方块显示总数与「已注册/未注册」等可后续补充。

## 6. 其他分类（P0 占位）

- 空态文案：`「生物/实体」分类还没有资料。在 DSH 对话里让 agent 创建。`；
- P0 不提供分类内的新增/编辑表单（按「agent 主操作」原则）；
- 卡片字段（未来）：名称、原名、简介、封面、分类、来源（原版/模组）、首次出现版本。

## 7. 交互与按钮

- 顶部：刷新、素材（现有）；
- 分类导航：点击切换；「添加新资料」点击后提示（弹窗/提示条）「让 agent 创建资料」；
- 物品/方块：保留搜索、列表/画布切换、打开编辑器；
- 其余分类：只读列表 + 空态。

## 8. 数据与接口

- P0 计数：前端从 `project.items.length` 取物品/方块；其余 0；
- P1 起：`content.catalog` 返回 `{ categories: [{ id, label, count }] }`（后端统计 items/entities/...）；
- 现有动作不变（`items.list/save` 等）；新增动作在对应分类实现时再加。

## 9. 迁移与测试

- 顶部页签 `items` → `mod-data`，label「mod 资料」；旧测试若断言「物品」页签需同步；
- 新增组件 `ModDataTab`（纯渲染分类框架）与 `ItemsSection`（迁移现有 `ItemsTab`）；
- 测试（P0）：
  - 渲染：页签出现「mod 资料」；
  - 分类导航 10 项可见、物品/方块选中；
  - 物品分类渲染现有物品与编辑器入口；
  - 其他分类空态文案含「让 agent 创建」；
  - 来源标签「原版资料 / 原版协议」可见。

## 2. 依赖顺序

```text
0.6.2 (T00/T10)
  → 0.6.3 (T20/T21/T22)
      → 0.6.4 (T30/T31/T32)
          ├→ 0.6.5 (T40/T41) ─┐
          └→ 0.6.6 (T50/T51) ─┴→ 0.6.7 (T60/T70) → 0.6.8 (T71/T72) → 0.6.9 (T80/T81/T82)
```

可并行：0.6.5 与 0.6.6 在契约与扫描就绪后；0.6.3 与 0.6.4 的只读部分可交叉，但写入口需等 T21。

## 3. 与既有版本的关系

- **v0.6.1（已发版）**：确认/事务/批次、素材 revision、预算、门禁保留；0.6.3 在其上统一，不重做。
- **原 v0.6.2「注册元数据补全」计划**：建议废弃，由本系列 0.6.5（属性）与 0.6.6（关系）覆盖；已有的 item-props 修复（6be0e1b）作为过渡保留。
- 每个版本独立提交、独立验收，不把多批工作压进「0.6.2 已完成」。

## 4. 系列验收门

1. 每版任务有正/负向测试，全量测试保持绿；
2. 未验证项单列，不用「UI 值变了」或「工具返回 ok」代替重读；
3. 不完整扫描不产生破坏性删除；
4. 真实工程只用副本，不碰作者原工程；
5. 版本号与发布由作者确认，不自动 bump/安装。

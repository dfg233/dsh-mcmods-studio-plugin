## 1. 背景与根因

### 1.1 mod_boat 误判

- `lib/registry-scan.js` 类型正则只匹配简单泛型：
  `/DeferredRegister\s*<\s*([A-Za-z0-9_.]+)\s*>\s+([A-Za-z0-9_]+)/`
  嵌套泛型 `DeferredRegister<EntityType<ModBoatEntity>>` 匹配失败 → `ENTITY_TYPES` 不在类型表 → `mod_boat` 未归入「实体注册」；
- 旧扫描 `scanRegistryNames` 把非创造标签文件的 `register("id")` 全当物品，作为回退时会带入实体；
- v0.6.0 的 `removed` 只清理「资源可解释」的残留，`mod_boat` 无资源 → 旧条目留存。

### 1.2 属性未显示

- `lib/import.js` 的 `syncEntries` 创建条目时统一 `defaultProperties()`，未解析注册表达式；
- TutorialMod 写法可静态解析：`durability(127)`、`SwordItem(Tier, dmg, speed, ...)`、`PickaxeItem(Tier, ...)`、`ArmorItem(Material, Type.X, ...)`、`ModCreativeModeTabs` 的 `accept(...)`。

## 2. 目标与非目标

### 目标

1. 实体/其他注册类型的 id 不再进入物品列表；旧残留可清理；
2. 导入时填入耐久、伤害/速度、工具/采集等级、护甲、创造栏、食物（只填空值）；
3. Client 只提交最新项目/素材请求，缓存按 revision 失效；
4. 上下文预算为硬边界；索引来源可信；增量扫描不重复解析；
5. 仓库内最小门禁与文档数字校验。

### 非目标

- 不解析复杂表达式（三元、方法调用结果）——解析不了写提示，不猜测；
- 不覆盖用户手改的属性值；
- 不做真实浏览器自动化（保留假 React 装置 + 渲染快照）。

## 3. 设计

### 3.1 注册识别补全（A）

- 泛型正则支持嵌套：`/DeferredRegister\s*<\s*([A-Za-z0-9_.?<>,\s]+?)\s*>\s+([A-Za-z0-9_]+)/`；
- 归类增加：`entities`（EntityType）、`blockEntities`、`effects`、`enchantments`、`sounds`、`particles`、`fluids`、`tabs`；
- 返回 `{ blocks, items, creativeTabs, entities, others, warnings }`；导入时用于「排除」与「清理候选」；
- `scanRegistryNames`（旧回退）同时增加实体过滤，避免回退路径带入实体。

### 3.2 属性提取（B，新增 lib/item-props.js）

| 模式 | 字段 |
| --- | --- |
| `.durability(n)` | `maxDamage` |
| `SwordItem(T, dmg, speed, ...)` | `attackDamage`、`attackSpeed`、`toolTier` |
| `PickaxeItem` / `ShovelItem` / `AxeItem` / `HoeItem` | `toolTier`、`miningLevel` |
| `ArmorItem(M, Type.HELMET)` 等 | `armor`（1/3/2/1） |
| `Tiers.X` / 自定义 Tier 常量 | `toolTier` 名称、`miningLevel`（原版 0–4 映射） |
| `Item.Properties().food(...)` | `foodNutrition`/`foodSaturation`（仅 `ModFoods` 常量） |
| `ModCreativeModeTabs` accept 顺序 | `creativeTab` |

规则：只填空值；解析失败写 `loaderNotes` 提示；不猜复杂表达式。

### 3.3 导入写回与清理（C）

- `syncEntries` 调 `extractItemProps`，新条目填入；merge 时只填空字段；
- `removed` 增加「实体/其他注册类型的旧条目」（即使无资源）；
- `import.pruneEntries` 同步支持这些类型。

### 3.4 Client 一致性（D）

- 请求代次：`boot`/`project.open`/`assets.list` 带递增代次，仅最新可提交；项目与素材同代次提交；
- 切换项目清空旧操作目标；`assets.list` 返回 `revision`（mtime/size 汇总），图片与预览 effect 依赖 revision。

### 3.5 上下文预算（E）

- `context.pack` 用 `Buffer.byteLength` 计 UTF-8 字节；
- 裁剪顺序：长文本 → 列表 → 最小元数据；最终必须 ≤ 预算；不可裁的超限明确报错；
- 预算参数上界 256KB。

### 3.6 索引与增量扫描（F）

- 静态回退只扫 `gradle.properties` 声明的 MC/Forge 版本；索引记录 `source`/`confidence`；缓存键加入 JAR 指纹（路径+size+mtime）；
- `structure.refresh` 先 hash 后解析，未变文件复用；删除检测用集合差。

### 3.7 门禁与文档（G）

- `package.json scripts`：`lint:syntax`、`test`、`gen:schema`、`check:docs`；`engines.node >= 20`；
- 文档数字（动作/工具/模板/测试）由脚本校验。

## 6. 风险

| 风险 | 应对 |
| --- | --- |
| 正则提取误判复杂表达式 | 只处理明确模式；失败写提示不猜测 |
| 覆盖用户手改属性 | 只填 `null/0/空` |
| 自定义 Tier/材质解析不到 | 保留名称，数值留空并提示 |
| 实体清理误删手写条目 | 只清理注册类型集合内的 id |
| Client 改动回归 | 先抽状态与纯函数；渲染快照测试保护 |
| 预算裁剪影响上下文质量 | 保留最小元数据 + 截断说明 |

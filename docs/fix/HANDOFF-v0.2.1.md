1. 历史回滚默认「**回到该步**」：保留该步结果，只撤销该步之后的步骤；目标步骤保持 active，后续步骤标记 rolledBack。

## v0.2.1 要做的两件事

### 1. 修复 Pattern / 材料键无法换行

根因：受控 `Textarea` 每次输入都 `split → filter 空行 → join`，按 Enter 产生的末尾空行立刻被过滤。

方向：输入阶段保留原始文本（含空行、末尾换行、Pattern 空格），保存/预览时再解析；不要每次输入都写回数组。

### 2. 内容历史

- 新增 `.mcstudio/content-history.json`；
- 每次 `content.apply` 记录一步，备份仍放插件数据目录；
- 选择某步：从最后一步逆序恢复到目标步之后，目标步保留，后续标记 `rolledBack`；
- 回滚后不删除记录/备份；下一次成功修改时把旧 `rolledBack` 归档；
- 新增 `content.history.list`、`content.history.rollback`；保留旧 `content.rollback`；
- UI 用常驻「历史记录」替代 `lastContentBackup` 单次提示。

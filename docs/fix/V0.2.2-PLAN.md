# v0.2.2 物品编辑器贴图预览修复

> 版本：v0.2.2（PATCH）
> 状态：已确认、已实现、已验收（2026-10-31）
> 关联：[../fix/README.md](README.md)、[../VERSION-PLAN.md](../VERSION-PLAN.md)、[../STATUS.md](../STATUS.md)

## 0. 摘要

物品编辑器的「贴图」栏始终显示「无」，即使贴图已经上传；列表与画布缩略图正常。

## 1. 根因

`ItemsTab` 用 `assets.readMany` 批量读取缩略图，返回键是 `item/<id>`（方块用解析出的主贴图名）。
`ItemEditor` 却用 `images[draft.id]` 取值，键永远匹配不上，因此贴图栏恒为空。
列表、画布与素材页都用各自的正确键，只有编辑器受影响。

附带问题：在编辑器内上传贴图后，`ItemsTab` 没有把「重新读取缩略图」的能力传给它，
预览要关闭重开才会更新。

## 2. 修复

- `ItemsTab` 向 `ItemEditor` 传 `imageFor(id)`（内部走 `thumbKey`）与 `onTextureUploaded`；
- `ItemEditor` 改用 `imageFor(draft.id)` 渲染预览，不再直接按 id 查 `images`；
- 上传成功后调用 `onTextureUploaded`，重新读取缩略图并刷新素材列表。

## 3. 验收

1. 已上传贴图的物品，打开编辑页「贴图」栏显示缩略图；
2. 未上传贴图的物品仍显示「无」；
3. 在编辑页上传 PNG 后，预览立即出现，不需要关闭重开；
4. 列表 / 画布缩略图不受影响；
5. 全量测试通过（18 个文件 / 196 项）。

# v0.2.4 注册表清理工具补全

> 版本：v0.2.4（PATCH）
> 状态：已实现、已验收（2026-11-01）
> 关联：[../fix/README.md](README.md)、[../VERSION-PLAN.md](../VERSION-PLAN.md)、[../STATUS.md](../STATUS.md)、[../INDEX.md](../INDEX.md)

## 0. 摘要

Agent 用 `project_create` 创建项目后删除项目目录，需要清理注册表中的登记，
但插件只提供 HTTP 动作 `projects.remove`，没有对应的 agent 工具，只能绕过插件直接改 `registry.json`。

## 1. 根因

- `lib/tools.js` 的 22 个工具中没有「移除项目登记」；
- 目录被删除后，`project_list` 仍会列出该项目（`ok: false`），agent 没有清理入口；
- 直接改注册表文件容易破坏 `lastProject` 等字段的一致性。

## 2. 修复

- 新增 agent 工具 `project_remove { path }`：
  - 调用 `forgetProject` 移除登记，不删除项目目录与 `.mcstudio/`；
  - 目录已不存在时也能移除（只按路径匹配）；
  - 未登记时返回 `removed: false` 与说明，不报错；
  - 返回 `{removed, path, projects[]}`，`projects` 为剩余登记的 `{path,name,modid}`。
- 工具数 22 → 23；动作数不变（`projects.remove` 早已存在）。

## 3. 验收

1. 创建项目后调用 `project_remove`，登记被移除；
2. 移除后 `project_list` 不再包含该项目；
3. 项目目录与 `.mcstudio/project.json` 保留；
4. 目录已删除时仍可移除登记；
5. 未登记路径返回 `removed: false`；
6. 全量测试通过（19 文件 / 212 项）。

## 4. 测试

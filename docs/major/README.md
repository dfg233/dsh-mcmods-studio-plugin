> 规则：一个主要版本一份计划；PATCH 修复计划仍在 [../fix/](../fix/README.md)，模块设计见 [../design/](../design/README.md)。

## 约定

- 文件命名：`V<主版本>.<次版本>.0-PLAN.md`，例如 `V0.3.0-PLAN.md`、`V0.4.0-PLAN.md`；
- 计划内容包含：目标与非目标、模块拆解、接口与数据、实施顺序、验收、测试、风险、已确认决策；
- 实现完成后在文档内补验收记录，状态改为「已实现、已验收」；
- 版本号规则见 [../VERSION-PLAN.md](../VERSION-PLAN.md)。

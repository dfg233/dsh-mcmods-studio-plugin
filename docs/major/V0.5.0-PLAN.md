# v0.5.0 计划：完整的简单模组（M4）

> 日期：2026-11-15
> 版本：v0.5.0（MINOR）
> 状态：**方案已确认（2026-11-15），待实施**
> 关联：[PLAN.md](../PLAN.md) M4、[V0.4.5-PLAN.md](../fix/V0.4.5-PLAN.md)、[VERSION-PLAN.md](../VERSION-PLAN.md)、[DATA-FORMAT.md](../DATA-FORMAT.md)
> 定位：v0.5.0 的目标是「**完整的简单模组**」——按资料库分类覆盖原版内容类型，能通过插件 + agent 做出可编译可玩的简单模组；复杂功能初步实现。加载器本轮**仅 Forge**。

## 0. 方向与分类

内容类型按资料库分类组织（与设计参考一致）；「添加新资料」是入口，「原版资料 / 原版协议」是资料来源标签，不单独作为内容类型。

| 分类 | 说明 | v0.5 目标 |
| --- | --- | --- |
| 物品/方块 | 物品（Item）与方块（Block） | **覆盖**（现有 + 盔甲/细分模板） |
| 生物/实体 | 实体（Entity） | **覆盖**（实体、属性、刷怪蛋、生成） |
| 多方块结构 | 玩家搭建方块时触发的事件 | **初步**（检测 + 触发模板） |
| 游戏设定 | 名词术语、命令、世界观与背景故事 | **覆盖**（设定卡 + 命令模板） |
| 群系/群落 | 生物群系（Biome） | **覆盖**（biome + 特征 + modifier） |
| 附魔/魔咒 | 附魔（Enchantment） | **初步**（注册 + 语言） |
| 自然生成 | 结构（Structure）、地物（Feature）、拼图（Jigsaw） | **初步**（JSON 模板 + 校验） |
| 世界/维度 | 维度（Dimension） | **初步**（dimension JSON + 传送骨架） |
| BUFF/DEBUFF | 状态效果（Effect） | **初步**（注册 + 药水骨架） |
| 绑定热键 | 设置中新增的绑定按键 | **初步**（KeyMapping 模板） |
| 添加新资料 | 新建资料入口 | 已有（构想/设定卡由 agent 创建） |
| 原版资料 / 原版协议 | 资料来源标签 | 知识库元数据，不做内容生成 |

**「完整的简单模组」定义**：一个新建项目能按上表「覆盖」列添加/修改内容，并用模板 + 代码生成 + 内容编辑完成；「初步」列达到可运行骨架。

三条线：

1. **分类覆盖**：补齐生物、群系、自然生成、维度、效果、热键、多方块、游戏设定；
2. **复杂功能初步**：GUI/网络/持久化沿用 v0.4 模板，新增实体生成、群系特征与维度骨架；
3. **可测性能与文档**：100 物品 / 20 模块基准、示例模组说明。

## 3. 内容类型（按分类）

### 3.1 物品/方块（覆盖）

- 物品：普通、工具、食物、盔甲（新增盔甲模板）；
- 方块：普通、方块实体、方块状态（现有）；
- 模板：`simple-item`、`tool-set`、`armor-set`、`block-basic`、`registry-items`。

### 3.2 生物/实体（覆盖）

- 注册：`DeferredRegister<EntityType<?>>` + `EntityType.Builder`；属性：`EntityAttributeCreationEvent`；刷怪蛋：`ForgeSpawnEggItem`；
- 生成：`SpawnPlacements.register` + `BiomeModifier`（1.20.1 写法）；
- 实体骨架：`extends Monster/Animal` + `createAttributes` + `registerGoals`；
- 模板：`entity-basic`、`spawn-egg`、`entity-attributes`、`entity-spawn`；
- API/UI：内容页「生物」条目（类别、尺寸、生命/攻击、刷怪蛋颜色、生成群系）；
- 校验：注册配对（EntityType + 属性 + 刷怪蛋）、资源存在。

### 3.3 多方块结构（初步）

- 定义：玩家搭建方块时触发的事件（如祭坛/传送门框架）；
- 模板：`multiblock-basic`（检测脚下方块 + 触发逻辑骨架 + 语言）；
- API/UI：内容页「多方块」条目（结构尺寸、触发方块、效果）；
- 校验：方块引用存在。

### 3.4 游戏设定（覆盖）

- 设定卡：名词术语、世界观、背景故事（数据存 `.mcstudio/settings.json`，可导出文档/语言键）；
- 命令：`RegisterCommandsEvent` + Brigadier 骨架（模板 `command-basic`）；
- UI：构想页之后新增「设定」轻量列表（只读，agent 创建）；
- 校验：名称/命令不冲突。

### 3.5 群系/群落（覆盖）

- 数据：`data/<modid>/worldgen/biome/<id>.json` + `worldgen/placed_feature` / `configured_feature`；
- 注入：`data/<modid>/forge/biome_modifier/*.json`；
- 模板：`biome-basic`、`biome-feature`、`biome-modifier`；
- API/UI：内容页「群系」条目（温度、降水、特征、权重）；
- 校验：JSON 合法、特征引用存在、modifier 指向正确。

### 3.6 附魔/魔咒（初步）

- `Enchantment` 注册骨架（1.20.1 编码式）+ 语言；
- 模板：`enchantment-basic`；
- 校验：注册名与语言键。

### 3.7 自然生成（初步）

- `worldgen/structure`（结构）、`configured_feature` / `placed_feature`（地物）、`jigsaw`（拼图）；
- 模板：`structure-basic`、`feature-basic`、`jigsaw-basic`；
- 校验：JSON 合法、引用存在；不承诺完整生成。

### 3.8 世界/维度（初步）

- `data/<modid>/dimension_type` + `dimension` JSON；传送门/传送骨架（事件）；
- 模板：`dimension-basic`；
- 校验：JSON 合法、类型引用存在。

### 3.9 BUFF/DEBUFF（状态效果，初步）

- `MobEffect` 注册 + `Potion` 骨架；
- 模板：`effect-basic`；
- 校验：注册名与语言键。

### 3.10 绑定热键（初步）

- `KeyMapping` 注册 + `RegisterKeyMappingsEvent` + 客户端事件骨架；
- 模板：`keybind-basic`；
- 校验：键位名唯一、语言键。

### 3.11 添加新资料（入口）

- 构想页 / 设定卡的「新建」由 agent 在 DSH 对话中完成；UI 只读；
- 无独立数据文件（构想复用 `features.json`，设定用 `settings.json`）。

### 3.12 原版资料 / 原版协议（资料来源标签）

- 作为知识库元数据（导入来源、协议声明），不做内容生成；
- 导入时记录 `source: vanilla | mod`、协议字段。

### 3.13 支撑内容

- 配方扩展（切石/锻造/烟熏/营火）、战利品表（方块常规掉落）、创造标签成员（代码标记）、标签/语言/模型；
- 声音/粒子（初步）：`sounds.json` + `SoundEvent`、`ParticleType` 注册骨架。

## 5. 简单模组示例（端到端）

示例项目覆盖分类：

- 物品/方块：红宝石、红宝石剑、盔甲、红宝石块（带掉落）；
- 生物：红宝石傀儡（属性/刷怪蛋/生成）；
- 群系：红宝石洞窟（特征 + modifier）；
- 自然生成：洞窟特征/拼图；
- 世界/维度：红宝石维度（骨架）；
- 附魔/效果：红宝石附魔、效果；
- 多方块：红宝石祭坛；
- 游戏设定：术语「红宝石」、命令 `/ruby`；
- 绑定热键：`R` 打开红宝石界面；
- 支撑：配方（切石 + 锻造）、战利品表、标签、语言、模型、创造标签成员。

验收：空项目 → agent 建模块/阶段/任务 → 内容编辑 + 模板生成 → `gradlew compileJava` 通过 → `runClient` 能看到内容（人工）。

## 10. 风险

| 风险 | 应对 |
| --- | --- |
| 生物/群系/自然生成代码差异大 | 只做骨架 + 标记；编译验证兜底 |
| 群系/结构 1.20.1 数据驱动复杂 | 先做 JSON 模板 + 校验，复杂生成后续 |
| 维度骨架需要传送逻辑 | 只做 JSON + 简单传送事件模板 |
| 模板数量膨胀 | 只做高频类型；模板可组合 |
| 性能基线受机器影响 | 固定 fixture + 记录环境 |
| 示例工程耗时 | 文档说明 + 脚本生成，不提交二进制 |

## 11. 已确认的决策（2026-11-15）

1. **加载器**：本轮**仅 Forge**，NeoForge / Fabric 暂不考虑。
2. **方向**：做「完整的简单模组」——按资料库分类覆盖原版内容类型，复杂功能初步实现。
3. **分类体系**：采用资料库分类（物品/方块、生物/实体、多方块结构、游戏设定、群系/群落、附魔/魔咒、自然生成、世界/维度、BUFF/DEBUFF、绑定热键；「添加新资料」为入口，「原版资料/原版协议」为资料来源）。
4. **战利品表**：只做方块常规掉落。
5. **创造标签**：成员写入代码标记（1.20.1 只能代码注册）。
6. **性能**：采用第 6 节目标（本机基线）。
7. **示例**：文档说明 + 脚本形式，不提交二进制示例工程。
